# 鳥海理論 (Toriumi Theory)

**Self-Referential Irreducibility as a Constructive Proof of Free Will**

---

## What is this?

The Toriumi Theory proves that free will exists as a **structural property** of self-referential computation. It is neither deterministic (predictable) nor random — it is a **third category**: self-referentially irreducible choice.

## Files

| File | Description |
|---|---|

| `toriumi_deep.py` | Deep mathematical structures: ergodicity, non-commutative algebra, Darwin system, critical state, Zeno boundary |
| `toriumi_paper.md` | Full paper draft — 11 chapters |
| `toriumi_paper.tex` | LaTeX version for arXiv/OSF submission |

## Quick Start

```bash
python toriumi_agent.py
```

The agent makes 30 binary choices. Before each choice, it predicts what it will choose. The prediction and the actual choice diverge 50% of the time — because the act of self-simulation changes the agent's state. No randomness is used.

```bash
python toriumi_deep.py
```

Runs the 5 deep structures: ergodicity breaking, non-commutative algebra, Darwin system, critical phase transition, and Zeno boundary analysis.

## Core Theorem

For any self-referential decision system, the Toriumi Gap rate is approximately 1 - 1/|O|, where |O| is the number of options. For binary choices, the gap is ~50%.
